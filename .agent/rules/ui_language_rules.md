# UI Language Rules

## Policy
1. **Strict English UI**: All user-facing UI text inside the Android application must be in **English**.
   - Includes:
     - Screen titles and app bar actions
     - Contextual menus and dropdown items
     - Dialog titles, descriptions, buttons ("Confirm", "Cancel", "Overwrite", "Keep Both")
     - Toast messages and in-app notifications
     - Progress bars and status labels ("Deleting", "Preparing upload", "Extracting...")
     - Error messages displayed to the user
2. **Vietnamese for Communication Only**: Vietnamese should only be used when communicating with the developer/user in chat, never hardcoded into strings or Composable UI components.
